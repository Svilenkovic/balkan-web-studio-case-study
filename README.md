## Purpose

Remote work needs more than a translated contact page. This project explains how research, review windows, written decisions and staged delivery keep an international website project understandable across locations.

## Design direction

The site is a solar atlas. Cobalt space, gold arcs and coral markers trace work across time zones, with the route changing as the reader advances.

## What I built

- English-first project information with a full Serbian counterpart
- A process for asynchronous review and recorded decisions
- International project pages without false local offices or team claims
- A solar path used to explain timing and handoffs
- Contact and privacy pages written for cross-border enquiries

## Release checks

Every canonical route was checked at 390, 768, 1440 and 1920 px. The release was also tested without JavaScript and with reduced motion. Live checks covered HTTPS, redirects, response headers, structured data, sitemap files, protected paths and invalid contact requests without sending test mail.

These are engineering checks, not claims about search ranking or field performance.
